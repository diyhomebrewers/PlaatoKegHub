Device to retrieve data from the Keg Plate designed on the other side of diyhomebrewers.com, designed to be able to be installed inside the keg if there is a device or format that can be plugged into the exterior using any USB without physical modification.

- You can also use local formats (without internet, including WiFi).
- With current services like taplist, Brewfather, HTTP, MQTT (Home Assistant)...
- Integrate with the CLOUD of Diyhomebrewers and the free pizza manager.
- Lose the calibration or the original values ​​of the plate.
- It is not necessary to remove or remove it physically (not intrusive), although it is recommended for a more compact assembly.
